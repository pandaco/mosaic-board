Logo assets for MosaicBoard

Files:
- logo-symbol.svg — compact square symbol (use for favicon, app icon, small UI elements)
- logo-horizontal.svg — horizontal symbol + wordmark (primary header/logo)

Colors:
- Primary text / icon color: #2D3748 (dark slate)
- Background light: #F8FAFC

Recommended sizes:
- Symbol (favicon): 32x32, 48x48, 128x128
- Symbol large (app icon): 240x240 (provided)
- Horizontal: use at 240–520px width for headers; scale down to 160px for small headers

Usage notes:
- Use the symbol for compact spaces and the horizontal logo for top nav or onboarding screens.
- Keep adequate clear space (approx. 1x symbol width on left/right when used with text).
- SVGs are vector; prefer to embed inline or use as src for <img> to preserve crispness.
